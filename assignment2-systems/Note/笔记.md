## NVTX

**NVTX 是 NVIDIA 提供的一套标注库/API**，全称是 **NVIDIA Tools Extension**。它让你给代码片段添加名字，方便性能分析工具识别。

在 CUDA 版 PyTorch 中，可以直接使用 `torch.cuda.nvtx` 接口，无需另外安装 Python 的 `nvtx` 包。

最常用的是 `with`：

```python
import torch.cuda.nvtx as nvtx

with nvtx.range("forward"):
    logits = model(inputs)
```

这里：

- 进入 `with` 时，开始一个名为 `forward` 的标注区间。
- 执行区间内的代码。
- 离开 `with` 时，结束该区间。

`nvtx.range` 也可以作为装饰器，标记整个函数。

**标签需要配合 Nsight Systems 才方便查看。** 在已安装 `nsys` 的 GPU 环境中，可以这样启动现有脚本：

```bash
uv run nsys profile \
  --trace=cuda,nvtx \
  --output=results/profile \
  -- python -m cs336_systems.benchmark --device cuda --mode train
```

之后打开生成的 `.nsys-rep` 报告，就能看到 `forward` 区间，以及由这段 CPU 代码发起的 GPU 活动。

| 工具或接口                 | 作用                           |
| -------------------------- | ------------------------------ |
| NVTX                       | 给代码片段添加标签             |
| Nsight Systems             | 采集执行信息，展示时间线和统计 |
| `torch.cuda.synchronize()` | 等待 GPU 完成任务              |
