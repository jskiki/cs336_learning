# 2.1.3 端到端基准测试总结

本节覆盖 benchmarking_script 的（a）、（b）、（c）；不包含后续 FlashAttention、DDP、FSDP 等题目的正确性测试。

## 实验配置与计时口径

- 测量时间：2026-11-12T17:39:31.182447+08:00 至 2026-11-12T17:50:13.046709+08:00。
- 硬件：Modal NVIDIA B200；每次仅使用一张 GPU、请求 4 个 CPU 核和 16 GiB 主机内存。
- 环境：PyTorch 2.11.0+cu130；float32 参数；CUDA matmul TF32 设置为 `False`。
- 固定配置：vocab_size=10000、batch_size=4、context_length=512、seed=42、AdamW lr=0.001；每组正式测量 10 步。
- 保持未优化的基线：未启用 torch.compile、自动混合精度、FlashAttention 或激活检查点。
- 每组在独立 Python 进程中初始化模型和随机批次；同一组内预热与测量复用该批次。各组顺序执行，结果时间戳使用 Asia/Singapore。
- 使用 timeit.default_timer；初始化与数据准备后先同步，每个计时步骤结束时同步 CUDA。Modal 排队、镜像构建、容器启动、模型初始化、随机数据生成、日志及结果保存均不计时。
- forward 保留梯度记录；forward_backward 包含清梯度、前向、损失与反向；train 还包含优化器更新。每步独立计算梯度，不跨步累积。
- 分段实验在清梯度、前向、损失、反向、优化器更新后分别同步；它用于直接测量各阶段，不用不同模式相减估计。额外同步会改变流水重叠，分段总耗时不能替代端到端总耗时。
- 表格单位均为毫秒，表示平均值 ± 样本标准差（n−1）。OOM 表示实测显存不足，没有可用的完整十步统计值。

本次共保存 80 组记录：成功 72 组、OOM 8 组、其他失败 0 组。原始数据见 [b200-benchmark-suite-20261112](../results/b200-benchmark-suite-20261112/manifest.json)。
